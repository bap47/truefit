# TrueFit website

Web tĩnh Jekyll cho GitHub Pages + Pages CMS. Xem **HUONG-DAN.md** để đưa web lên và đăng bài.

- Nội dung: `_san_pham/`, `_khach_hang/`, `_posts/` (tin tức), `_chinh_sach/`, `_data/trang_chu.yml`
- Giao diện: `_layouts/`, `_includes/`, `assets/css/main.css`
- Animation: `assets/js/main.js` (hiện dần khi cuộn, đếm số, logo chạy ngang)
- CMS: `.pages.yml`
